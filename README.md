# Board_with_Attiny85_control_relay_220v
Board with Attiny85 for control relay, with pin for sensor and supply 220v AC

This PCB allows you to control a relay by programming an Attiny85. Five pins allow you to add sensors to your project. With a 220V power supply, it can be used for a variety of applications, from home automation to adding electronics to devices that don't already have them.
